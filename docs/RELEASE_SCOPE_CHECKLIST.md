# Public release checklist

## Included in the prepared release

- [x] Reviewer-driven EXP-A/EXP-B/EXP-C evidence archive and SHA-256 checksum.
- [x] Retained preprocessing source package.
- [x] Retained core model/smoke source package.
- [x] Retained validation-localization source package.
- [x] Retained fold-0 inference source package.
- [x] Retained pure-supervised five-fold source package.
- [x] Retained reliability-gated VR-SSL3D source/configuration package.
- [x] Retained conventional/Mean-Teacher benchmark package.
- [x] Retained gate-component ablation package.
- [x] Manuscript-context sources and citation metadata.
- [x] Verified core runtime environment notes.
- [x] No raw DICOM data or directly identifying metadata included.

## Required external actions before resubmission

- [ ] Confirm the repository owner/account approved by the authors.
- [ ] Create a public GitHub repository and upload this release folder.
- [ ] Verify that the repository opens without authentication.
- [ ] Freeze a versioned release/tag and record its exact public URL.
- [ ] Recompute the public-release SHA-256 manifest after upload contents are frozen.
- [ ] Insert the verified URL in the manuscript, Supplementary Information, and response letter.

Do not invent a repository URL and do not redistribute raw MORPH-CBCT DICOM data.
